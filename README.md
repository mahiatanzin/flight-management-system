# Flight Management System

A PHP & MySQL web app for booking flights, checking flight status, applying discounts, and rating past flights.

## Run locally
1. Install XAMPP and start Apache + MySQL.
2. Copy this folder into `xampp/htdocs/`.
3. Create a MySQL database named `Flight` in phpMyAdmin.
4. Update `config.php` if your MySQL username/password differ.
5. Open http://localhost/flight-management-system/homepage.php
